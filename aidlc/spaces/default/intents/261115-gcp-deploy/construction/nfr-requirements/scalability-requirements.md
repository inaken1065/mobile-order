# スケーラビリティ・容量・コスト要件: mobile-order の Google Cloud デプロイ

## Sources

- `[memory:M1]` `requirements.md` の NFR1（コスト）と、コスト見積もりの表、Constraints（VM 1 台、SQLite）

## 方針

スケールアウトとオートスケールは範囲外（`requirements.md` の Out of scope）。VM 1 台、SQLite のままとする。この文書では、容量の上限と、コストの上限を数値にする。

## 容量

- データ量: 注文とメニューのデータは、SQLite 数 MB 以下の見込み。30 GB のディスクに対して十分に小さい。ディスク使用率が 80% を超えたら、手順書に従って確認する。
- 同時利用: 自分だけの利用（客・厨房・店長の画面を、自分が切り替えて確認する）。複数端末の同時利用は、既存のポーリングの動作を変えず、本作業では扱わない。

## Assumptions & Open Questions

- `[assumption]` A1: データ量は、学習用の期間中に 1 GB を超えない。
- 未確定: Cloud Storage の state バケットの無料枠（Standard クラスの 5 GB 無料枠が、使うリージョンの対象かどうか）は、実施時に公式情報で再確認する（A5）。
